# 单句训练功能更新需求包

## 目的

为现有“口语跟练室”增加单句训练模式。用户先完整听完案例中的一句话，案例自动暂停，系统随后开始录制用户声音。录制结束后，用户可以连续播放案例原句和自己的录音，比较发音、语速、停顿与语气。

## 需求包内容

- [01-产品需求.md](./01-产品需求.md)：目标、范围、用户流程和功能规则。
- [02-交互与视觉规范.md](./02-交互与视觉规范.md)：页面布局、状态、按钮、文案和视觉要求。
- [03-验收标准与开发拆分.md](./03-验收标准与开发拆分.md)：验收用例、异常场景和开发顺序。

## 第一版完成定义

以下条件全部满足后，单句训练第一版才算完成：

1. 用户可以在“整段训练”和“单句训练”之间切换。
2. 单句模式只播放当前选中的一句案例。
3. 案例结束后自动暂停，并在短暂过渡后开始录音。
4. 案例播放期间不会录制用户声音。
5. 用户可以手动结束录音。
6. 用户可以分别播放案例、自己的录音，也可以按 A→B 顺序连续播放。
7. 用户可以重新录制、切换上一句或进入下一句。
8. 原有整段训练功能保持可用。
9. 桌面端和移动端均能完成核心流程。
10. 构建、数据校验和浏览器实际操作验证全部通过。

## 当前边界

- 第一版提供人工听辨和基础时长差异。
- 第一版不输出发音分数、文字准确率、重音判断或音高曲线。
- 录音保存在浏览器当前页面内存中，刷新页面后清除。
- 单句模式只要求麦克风权限；摄像头为可选项。
- 当前训练素材继续使用现有 `library.json` 中的逐句时间轴，无需修改数据集格式。
