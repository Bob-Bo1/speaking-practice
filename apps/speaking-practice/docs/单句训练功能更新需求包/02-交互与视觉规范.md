# 02 交互与视觉规范

## 1. 设计原则

单句训练延续现有黑白、克制、纸张感的视觉语言。新增视觉重点只放在“A 案例 → B 我的录音”接力状态上，其他区域继续使用现有组件和样式。

## 2. 页面结构

### 2.1 顶部模式切换

将顶部右侧的片段数量区域调整为模式切换，片段数量移动到左侧片段栏标题附近。

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 口语跟练室        作者选择                    [整段训练][单句训练] │
└─────────────────────────────────────────────────────────────────────┘
```

模式控件使用紧凑的分段按钮：

- 高度 34px。
- 外框使用 `--line-strong`。
- 选中项使用 `--ink` 背景和白色文字。
- 未选中项使用白色背景和 `--muted` 文字。
- 不使用新增强调色。

### 2.2 桌面端单句布局

保持现有三栏结构：左侧片段、中间视频与录音、右侧逐句提词器。

```text
┌──────────────┬────────────────────────┬──────────────────────────┐
│ 作者与片段   │ A 案例视频             │ 第 03 / 12 句            │
│              │                        │                          │
│ 01 片段      │ [当前句视频画面]       │ 当前训练句               │
│ 02 片段      │                        │ 字号加大、保持可读        │
│ 03 片段      │ A ━━━━━ → B ━━━━━     │                          │
│              ├────────────────────────┤ 上一句        下一句     │
│              │ B 我的录音             │                          │
│              │ [麦克风/可选摄像头]    │ 对比结果区                │
│              │ [听示范并开始]         │ A 案例  4.2s              │
│              │                        │ B 我的  4.8s              │
│              │                        │ [A→B 连续播放]            │
└──────────────┴────────────────────────┴──────────────────────────┘
```

### 2.3 移动端顺序

移动端按以下顺序纵向排列：

1. 模式切换。
2. 当前句文字。
3. 案例视频。
4. A/B 接力状态。
5. 录音区和主按钮。
6. 对比控制。
7. 片段列表和完整台词列表。

录音按钮和“下一句”按钮需要保持在首屏容易触达的位置。

## 3. A/B 接力状态

接力条是单句模式的主要状态提示。

### 待开始

```text
○ A 案例示范  ─────────  ○ B 轮到我
```

- 两段均为浅灰。
- 主按钮：“听示范并开始”。

### 播放案例

```text
● A 案例示范  ━━━━━━━━  ○ B 轮到我
```

- A 段使用黑色进度。
- 主按钮：“正在播放示范”，按钮不可重复点击。
- 可提供一个次要“停止”按钮。

### 录音中

```text
✓ A 案例示范  ─────────  ● B 正在录音 00:03
```

- B 段使用现有 `--record` 红色。
- 录音卡片边框变红。
- 主按钮：“我说完了”。

### 可以对比

```text
✓ A 案例示范  ─────────  ✓ B 已录制
```

- 两段恢复黑白状态。
- 主按钮：“A→B 连续播放”。
- 次要操作：“听案例”“听我的”“重新录制”“下一句”。

### 对比播放

- 播放 A 时，A 标签使用黑色实底。
- 播放 B 时，B 标签使用红色细边框和深色文字。
- 切换 A 到 B 时只做一次 150 毫秒淡入，减少零碎动画。

## 4. 当前句显示

- 当前句在右侧提词器中继续使用现有高亮规则。
- 单句模式下，当前句字号可提高约 10%。
- 当前句上方显示 `第 03 / 12 句`，使用 DM Mono。
- 已训练过的句子可以显示小型对勾；第一版只保留于当前页面会话。
- 点击其他句子会清除当前未保存录音，并将案例停在新句句首。

## 5. 对比结果区

对比区放在右侧提词器下半部，避免频繁打开模态窗口。

```text
对比本句

A  案例示范      00:04.2   [播放]
B  我的录音      00:04.8   [播放]

时长差：慢 0.6 秒

[ A→B 连续播放 ]
[ 重新录制 ] [ 下一句 ]
```

文案规则：

- 用户录音更长：`慢 0.6 秒`。
- 用户录音更短：`快 0.6 秒`。
- 差值小于 0.1 秒：`时长接近`。
- 只描述事实，不使用“优秀”“很差”等评价。

## 6. 控件文案

| 状态 | 主按钮 | 次要操作 |
| --- | --- | --- |
| 未授权 | 允许麦克风并开始 | 听案例 |
| 待开始 | 听示范并开始 | 听案例、上一句、下一句 |
| 播放案例 | 正在播放示范 | 停止 |
| 录音中 | 我说完了 | 无 |
| 生成录音 | 正在整理录音 | 无 |
| 可以对比 | A→B 连续播放 | 听案例、听我的、重新录制、下一句 |
| 播放对比 | 暂停对比 | 重新开始 |

## 7. 颜色与排版

继续复用现有变量：

| 用途 | 色值或变量 |
| --- | --- |
| 主文字与主按钮 | `--ink: #171717` |
| 次要文字 | `--muted: #767676` |
| 弱提示 | `--faint: #9b9b98` |
| 普通边框 | `--line: #deded9` |
| 强边框 | `--line-strong: #c9c9c3` |
| 卡片背景 | `--paper: #ffffff` |
| 页面背景 | `--paper-soft: #f7f7f5` |
| 录音状态 | `--record: #d43b34` |

字体继续使用：

- 中文正文与按钮：Noto Sans SC。
- 时间、步骤、A/B 标记：DM Mono。

圆角继续保持 5–8px，不增加大圆角胶囊和渐变背景。

## 8. 动效与声音提示

- 案例结束到录音开始只做一次状态切换。
- 录音开始时红点轻微扩散一次，持续动画控制在最低程度。
- 用户启用“减少动态效果”时关闭扩散动画。
- 第一版不强制播放提示音，避免提示音被录进开头。

## 9. 错误与空状态

### 麦克风被拒绝

```text
麦克风未开启
请在浏览器地址栏的权限设置中允许麦克风，然后重新开始。
[重新检查]
```

### 录音太短

```text
没有录到完整内容
请重新说一次，结束后点击“我说完了”。
[重新录制]
```

### 浏览器不支持录音

```text
当前浏览器无法录音
请使用最新版 Chrome 或 Edge。
```

### 当前句时间轴无效

```text
这句暂时无法训练
请选择其他句子。
```
